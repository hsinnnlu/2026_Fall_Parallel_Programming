# Lab1：Pixels in Circle（MPI）

計算半徑 r 的圓覆蓋多少個 pixel，輸出 `pixels mod k`。

```bash
mpicxx -O3 -o lab1 lab1.cc
srun -n <procs> ./lab1 <r> <k>
```

## 做法

- **只算八分之一圓**：圓對 y = x 對稱，只計算 x 落在 [0, D) 的部分（D 是對角線上的點數，用整數二分搜尋精確求出），最後 pixels = 2A + D。
- **增量更新 y**：每個 rank 只在起點用一次 `sqrtl` 算出精確的 ceil(sqrt(r² − x²))；之後 x 往右移時 y 只會變小，用整數比較往下調整，不再呼叫 sqrt。
- **平均分配**：[0, D) 按個數切給各 rank（最多差 1），最後用 `MPI_Reduce` 加總。
